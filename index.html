À propos de Seek It

Seek It est un moteur de recherche de personnes qui interroge plus de 22 milliards d'enregistrements issus de bases de données publiques et de fuites documentées.

Comment rechercher

La barre principale accepte :

  • Prénom + Nom : les deux séparés par un espace
  • Email : adresse email complète
  • Téléphone : numéro (avec ou sans indicatif)

Utilise le bouton Filtres avancés pour affiner par ville, code postal, département, pays, adresse, adresse IP, IBAN, BIC, année de naissance, genre ou fiabilité minimale.

Confidentialité

Aucune donnée n'est stockée sur nos serveurs. Les recherches sont anonymes et ne sont pas tracées.

5. RGPD et données personnelles

Aucune recherche n'est stockée sur nos serveurs. Aucun cookie de tracking n'est utilisé. Le stockage local (localStorage) est utilisé uniquement pour vos préférences d'affichage.
